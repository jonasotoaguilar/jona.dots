# Security

## Reporting a vulnerability

Do **not** open a public issue. Report privately:

- **GitHub private reporting**: Use the repository's private vulnerability reporting form at `PLACEHOLDER_private_reporting_url`.
- **Contact**: If unavailable, contact `PLACEHOLDER_security_contact` with the details below.

## What to include

- Affected project and version.
- Vulnerability description and impact.
- Reproduction steps.
- Proof of concept (if available).
