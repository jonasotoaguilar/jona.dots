# Runbook Guide

Use this guide when writing operational documentation.

## Core Practices

- State when to use the runbook
- List prerequisites, permissions, and tools
- Provide executable step-by-step procedures
- Include rollback steps
- Include escalation guidance when relevant

## Minimum Coverage

- Trigger conditions
- Required access
- Procedure
- Expected output or checkpoints
- Rollback
- Escalation path
