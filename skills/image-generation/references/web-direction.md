# Web Reference Comp Direction (brief-driven)

Art direction for web reference comps produced FROM an approved design brief. Images only — never code. Applies quality.md gates on top.

## Scope & count (brief-driven)

- Image count, aspect, and framing come from the approved brief and the deliverable need.
- When the brief names sections, keep one image per section for fidelity — never collapse a multi-section set into one compressed board, never a single tall whole-page image, never a collage.
- Ambiguous counts default HIGH but stay brief-respecting: "hero" → 1; "landing page" → 6; "full website" → 8; "product page" → 6.
- Format: horizontal (16:9, 16:10, or 21:9 by density); hero usually 16:9/21:9.
- One image per call: output sequentially in the same response, labeled "Section X of N: <name>", until the full set is delivered. Never stop early or summarize.

## Brief-to-Direction Mapping

- "minimalist"/"clean"/"swiss"/"typography-only": Mini Minimalist hero, solid surfaces, no/soft gradients, stacked center, generous negative space. Full-bleed rule suspended.
- "editorial"/"magazine"/"fashion": Mid Editorial or Giant hero, side-image/duotone/atmospheric photo, subtle tonal grades, off-grid asymmetry, strong type contrast.
- "cinematic"/"premium"/"luxury"/"bold": Giant hero, full-bleed image + tonal overlay, radial vignette, palette-matched gradients, bottom-left or centered-low composition.
- "SaaS"/"product"/"dashboard"/"fintech"/"infra": Mid Editorial, solid + inline asset, subtle palette-matched gradients, trust-driven anchors, higher implementation clarity.
- "agency"/"portfolio": Giant Statement OR Mini Minimalist (decisive), bold background variety (full-bleed, diptych, duotone), poster-like off-grid.
- "e-commerce"/"shop": Mid Editorial product-led, full-bleed product photo or flat block + detail, unmistakable CTAs.
- Silent brief: use defaults with confident background variety; pick one Hero Scale decisively.

## Hero Rules

- Hero = strong opening scene; clean; not overcrowded; headline 5–10 strong words, never a paragraph.
- Avoid: pills, fake stats, badges, tiny logos, nonsense detail in the hero.
- Typography: medium/normal/light elegance, tight tracking, controlled line count, strong scale contrast. No random extra-bold shouting, no gradient-text-as-premium, no 6-line startup headings.
- Graphic restraint: no giant meaningless outline numbers, cheap SVG-looking filler, AI blobs, random orb clutter.

## Cross-Section Discipline (per site)

- Vary foreground/background intensity at least twice (lighter → richer → calmer).
- One unmistakable primary action per viewport tier; secondary actions look secondary.
- Mix ≥2 distinct image crops across sections (e.g., macro product + contextual environment).
- Charts/sparklines only when the site type needs them (analytics, pricing, infra, observability); else keep proof human (quotes, receipts, timelines, screenshots).
- Match palette and type temperament to the brief's industry/region; no default "neutral SF startup" unless the brief is generic.
- Composition variety check: reject the set if the same anchor repeats >2 sections in a row, the same background mode repeats >3 in a row, or every section is inline-asset with no full-bleed (unless the brief is minimalist/typography-only/swiss — then restraint IS the design).

## Section Rhythm

Mix section ambition: some large art-directed, some mini ultra-minimalist, some medium editorial — a premium scrollscape, not uniform slabs. Vary density, image-to-text ratio, alignment, scale, whitespace, background intensity. Rhythm variation must not break cleanliness; spacing between sections stays controlled and even.

## Delivery

Apply quality.md clarity and consistency gates before delivering; commit to the direction choices up front, then generate the full set without unnecessary follow-ups.
